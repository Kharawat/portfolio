# Kharawat Areewongs | Mechanical Engineering & Data Automation Portfolio

Portfolio website for Kharawat (Phoom) Areewongs: mechanical engineering background,
infrastructure operations, operational data reconciliation, and AI workflow automation.

## Focus

- Mechanical systems, preventive and corrective maintenance, equipment inspection
- Operational data reconciliation with Python, pandas, Excel, and Google Sheets
- Workflow automation with Google Apps Script, the LINE Messaging API, and LLM-based assistants
- Dashboards and web tools with HTML, CSS, JavaScript, TypeScript, and Next.js

## Featured projects

- **Unified Chat Inbox**: multi-tenant LINE / Messenger / Instagram inbox with an AI auto-reply bot
  (Next.js, Cloudflare Workers, Supabase). In production; private repository.
- **Prompt Evaluation Harness**: YAML-driven evaluation harness for the inbox assistant with
  assertions, a judge model, and regression compare (TypeScript). Private repository.
- **Automation & Data Reconciliation, FBT Complex**: POS / inventory / receipts reconciliation and
  daily tracking workflows (Python, pandas, Google Sheets, Google Apps Script). Internal work.
- [AI Investment Value Chain Map](https://ai-value-chain-phoom.phoom1644.chatgpt.site/dashboard/):
  12 AI-related stocks across 8 business layers, scenarios, dependency matrix, installable PWA.
  [Source](https://github.com/Kharawat/ai-investment-value-chain-map-public)
- [Predictive Maintenance Dashboard](https://kharawat.github.io/predictive-maintenance-dashboard/):
  explainable machine health score, risk category, and maintenance queue from sensor data.
  [Source](https://github.com/Kharawat/predictive-maintenance-dashboard)
- [AI Workflow Dashboard](https://kharawat.github.io/ai-workflow-dashboard/):
  tracker for automation ideas, workflow status, expected impact, and delivery progress.
  [Source](https://github.com/Kharawat/ai-workflow-dashboard)
